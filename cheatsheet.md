# Terminal & Python Cheatsheet

## Terminal
- `mkdir name` : make a folder
- `cd name` : go into a folder
- `cd ..` : go up one folder
- `dir` : list files in the current folder
- `New-Item file.txt -ItemType File` : create an empty file

## Virtual environment
- `python -m venv venv` : create a venv
- `venv\Scripts\activate` : turn it on
- `deactivate` : turn it off

## pip
- `pip install package` : install a package
- `pip freeze > requirements.txt` : save the package list
- `pip install -r requirements.txt` : install from the list

## Python
- `python script.py` : run a script
- `print("text")` : show text on screen
- `name = "Abid"` : store a value in a variable
